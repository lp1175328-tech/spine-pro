# SpinePro Reminder 🦴

A smart reminder widget designed for students to maintain proper posture while studying.

## Features

- **Scheduled Reminders**: Set custom reminder times throughout the day
- **Audio Alert**: Plays a beep sound at scheduled times
- **Vibration Feedback**: Device vibrates when a reminder triggers (on supported devices)
- **Easy Management**: Add and remove reminder times with a simple UI
- **Status Toggle**: Turn reminders on/off with one click
- **Vietnamese Language**: Localized interface for Vietnamese-speaking users

## Default Reminders

- 09:00 AM
- 11:00 AM
- 2:00 PM

## How to Use

1. Open `index.html` in your browser
2. Click "Thêm" (Add) to add custom reminder times
3. Use the toggle to enable/disable reminders
4. Click "Xóa" (Delete) to remove any reminder

## Mobile Tips

⚠️ On mobile devices:
- Open the widget at least once
- Allow audio permissions for notifications to work properly

## Technologies Used

- React 18
- Tailwind CSS
- HTML5 Audio & Vibration API
